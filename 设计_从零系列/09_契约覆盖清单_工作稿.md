## 4. 非签名类硬语义核对清单（代码看不出、必须写进卡片）

> 来源：Codex 评价第 4 步 + 反提取中发现。09 每张契约卡须按此核对一遍。

1. **序列化格式**：A2A task_data/result 的 JSON 形态；Trace span 落库形态；审计行字段。
2. **事件循环所有权**：webUI 常驻 loop vs CLI asyncio.run vs 4 个 worker 所在 loop vs MCP server 独立进程；**对象不可跨 loop**（MCP stdio_client 的 TaskGroup 报错教训）。
3. **成对关系**：3 组 MCP client↔server；stdio/http 回滚成对（BILLAGENT_MCP_STDIO 两端都读）；注入参数成对（inject_agent_id ↔ server 参数名 agent_tag；inject_run_id ↔ run_id）。
4. **幂等/重试边界**：side_effect=True 永不自动重试；`CONNECTION_EXC` 判定可重连；`_call_server` 自带 2 次连接重试（引擎层 max_retry=0 防乘数效应）；bill_agent 崩溃禁直接重投（SIDE_EFFECT_AGENTS）；async_retry 谁在用。
5. **超时数值表（唯一事实源=config，09 复制数值并在 header 声明"改动走 config"）**：TOOL_TIMEOUT_SQL=30 / TOOL_TIMEOUT_LLM=300 / wait_result=240 / MODEL_TIMEOUT=240 / EXTERNAL_LLM_TIMEOUT=300 / USER_DOCS_TIMEOUT=60 / SANDBOX_MEMORY_MB=2048 / ASK_ROUND_LIMIT=3。
6. **上下文归属**：run_id/parent_span_id 须经 task_data 显式传递（contextvars 不跨协程）。
7. **锁**：utils.common db_lock + busy_timeout 5s；habit.upsert async 协程内持锁（LocalAdapter to_thread 丢锁教训）。
8. **回滚/兜底**：MCP_STDIO_FALLBACK；外部模型失败回退本地；user_docs 同步构建由 to_thread 控制；long_memory 静默 False。
9. **审计/埋点**：哪类调用写审计（llm.chat auditable=False 防刷屏）；tracer 失败不阻断。
10. **LLM 可见性边界**：InvokeContext（agent_id 等）不进 params_schema，防 LLM 伪造提权；params 不转译（num_predict≠max_tokens）。
