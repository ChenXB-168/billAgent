# 餐饮省钱策略（个人经验）

1. **做饭 vs 外卖**：一顿外卖平均 20-25 元，自己做（买菜+米面）约 8-12 元。每周至少 3 天自己做饭，一月能省 200 元以上。
2. **集中采购**：周日去市场一次买齐一周的菜（肉分装冷冻），避免平时临时点外卖。
3. **时令蔬菜**：什么季节吃什么菜（7 月西瓜 1.5 元/斤，冬天要 5-8 元/斤）。
4. **拼单/优惠券**：平台优惠券只在满减门槛内凑单，不为凑单多买非必需品。
5. **单位食堂**：能蹭食堂就蹭食堂，比外卖便宜一半还健康。

> 原则：省在"结构性支出"（食材/房租/交通），不在"小确幸"上抠。
