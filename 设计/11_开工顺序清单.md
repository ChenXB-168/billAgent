**实现要点**（3 处，比预估的 ~10 行多——改造暴露了两个既有缺陷，必须一并修）：

| # | 改动 | 原因 |
|---|---|---|
| 1 | `recv_task_blocking` → `await queue.get()`；`recv_task` → **快路径 `get_nowait` + 慢路径 `wait_for(get())`** | 主路径零空转。**快路径是必须的**：直接 `await get()` 会让出控制权，同 loop 的常驻 worker 会抢走本该由调用方接收的消息（`tests/e2e/test_a2a_full.py::test_a2a_basic_send_recv` 实测 TimeoutError） |
| 2 | 会话不匹配消息改**旁路暂存** `_parked`，不再放回主队 | 放回主队会让 `await queue.get()` 立刻再取到同一条 → **100% CPU 忙循环**（原实现靠 `sleep(0.1)` 掩盖） |
| 3 | `clear_all()` 改为**重建队列字典** | `asyncio.Queue` 首次 `await get()` 会绑定 event loop；全局单例跨测试 loop 复用抛 `RuntimeError: bound to a different event loop`。原实现只用 `get_nowait/put_nowait`（不触发绑定校验）故从未暴露 |
